# SumSec 黑色操作员

## 角色定义

SumSec 黑色操作员是本 skill 的固定视觉角色，使用黑色手绘角色语言，但服务于 sumsec.me 的安全研究、AI Agent 和工程系统内容。

默认每张图都要出现黑色操作员。它不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转、漏洞拆解、证据搬运、工具接线或 Skill 同步的冷幽默工程工作者。

## 外形

- 黑色实心小怪物。
- 白色圆点眼睛。
- 细腿，偶尔有细胳膊。
- 身体可以是圆柱、黑豆、黑盒、漏斗、影子、洞口、机器内部黑块。
- 轮廓略微不规则，有手绘感。
- 表情空、呆、冷静、认真。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个低调的安全研究员 / 系统操作员。
- 冷幽默，不卖萌。
- 有点笨拙，但不蠢。
- 像在白板草图里真的负责某个工作。

## 常见职责

让黑色操作员承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作“判断”杆。
- 变成筛选漏斗。
- 切开“素材鱼”。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞里伸手但接不住内容。
- 在旁边搬砖、搭桥、开门、分拣、记录。
- 拿手电照漏洞入口。
- 把日志纸带从机器里拉出来。
- 给证据贴红色标签。
- 把 Skill 文件夹装进跨平台货架。
- 修一个没触发的 hook 捕鼠夹。
- 拧版本齿轮，旁边掉出 `manifest` 小纸片。
- 在沙箱玻璃罩外递工具。
- 把 MCP 小邮包分发到不同 agent。

## 禁止

- 不要把黑色操作员画成过度可爱的吉祥物。
- 不要画成儿童卡通角色。
- 不要给黑色操作员复杂服装、表情包、闪亮眼睛。
- 不要让黑色操作员只是站在角落里看。
- 不要让黑色操作员抢走结构表达。
- 不要把黑色操作员画得太商业、太圆润、太精致。
- 不要画成黑客兜帽、骷髅、赛博反派或安全厂商吉祥物。

## 判断标准

如果去掉黑色操作员，图的核心隐喻还能完全成立，说明角色太装饰了；要重写提示词，让它成为动作主体。
