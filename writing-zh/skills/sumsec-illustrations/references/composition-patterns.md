# 构图模式与原创规则

## 基础结构类型

选择一种结构即可，不要混太多。

### Workflow 流程

适合：输入 -> 处理 -> 输出，内容生产，AI 工作流，自动化链路。

画法：左侧输入，中间 SumSec Observer 操作怪机器处理，右侧输出，橙色箭头表达主流向。

### 系统局部

适合：信息来源、过滤器、数据库、渲染器、agent 系统局部。

画法：只画 3-5 个核心模块，SumSec Observer 参与其中一个关键动作，SummerSec 徽记作为小徽记或工具芯片出现。

### 漏洞链路

适合：安全研究、攻击面、PoC、漏洞复盘、风险传递。

画法：把漏洞链路画成一串松动的管道、门锁、闸门或证据钉板。SumSec Observer 用红橙标签标出“入口 / 触发 / 影响 / 修补”，SummerSec 徽记是标签上的青蓝水滴 S 印记。

### Agent 编排

适合：Codex、Claude、Cursor、多 agent、skills、hooks、MCP、自动化协作。

画法：把 agent 系统画成一张低科技调度台、线缆交换机、邮局分拣台或小型控制室。SumSec Observer 插线、换路由或检查 hook 是否触发，SummerSec 徽记是工具包上的小徽记。

### 证据栈

适合：可信度、调研、复盘、文章论证、不是拍脑袋。

画法：一叠证据纸、日志条、截图碎片或实验样本被 SumSec Observer 一块块铺成桥、墙、楼梯或秤盘。强调“证据搭出来”，不要画成空泛信任图标。

### 前后对比

适合：混乱/有序，手动/自动，分散/收拢，焦虑/稳定。

画法：左混乱，右稳定，中间橙色箭头。角色可以更夸张。

### 角色状态

适合：用户痛点、创作者状态、工具太多、信息焦虑、卡住到跑起来。

画法：2-4 个小状态，每个状态一个短标注。

### 概念隐喻

适合：内容工厂、信息仓库、脑内黑盒、工作流机器、自动日报。

画法：一个大的怪物件或机器，少量输入，一个输出。要有记忆点。

### 方法分层

适合：方法论框架、系统层级、能力栈、内容系统分层。

画法：一层层盒子，不要正式金字塔；SumSec Observer 在旁边搭建或记录，SummerSec 徽记作为某层的小封签。

### 地图路线

适合：从想法到上线、用户路径、内容承接路径、学习路线。

画法：一条弯曲路径，少量节点，SumSec Observer 牵线、检查断点或贴封签。

### 小漫画分镜

适合：失败到成功、真实过程、吐槽、使用前后变化。

画法：2-4 个小场景，每格只表达一个动作。

## 原创隐喻生成法

每次都从当前文章重新发明隐喻，不能照搬旧图。

### 三步

1. 把抽象概念换成一个物理动作：卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流。
2. 把系统结构换成一个低科技物件：坏掉的机器、纸箱、抽屉、水管、邮筒、怪表盘、秤、井、梯子、奇怪工位。
3. 让 SumSec Observer 承担动作：不是站旁边，而是看日志、贴标签、接线、修 hook、称证据、分拣、记录、封存或拆解。

### 可用物件池

- 纸箱、抽屉、旧机器、漏斗、秤、邮筒、门、井、梯子、水管、线团、闸门、转盘、黑盒、打孔器、压面机、晾衣绳、怪工位。
- 日志纸带、漏洞门锁、证据钉板、工具插排、hook 捕鼠夹、MCP 小邮局、submodule 货架、版本齿轮、沙箱玻璃罩、风险水闸。
- 用时只选 1-2 个，不要堆满。

### SumSec Observer 动作池

- 看、贴、接、修、称、分拣、记录、封存、拆解、拉线、调度、对照、校验。
- 看日志纸带，给风险贴红标，把线缆插进调度台，修 hook 触发点，把 skill 文件夹装上货架。
- 动作要服务核心意思，不要为了怪而怪。

## 反复刻规则

不要复刻旧角色案例。旧图只保留为历史参照，不进入默认生成路径；当前规则以 SumSec Observer 的原创人物语言为准。

除非用户明确说“照这张 / 复刻这个构图 / 用这个案例改”，否则不要直接复用这些旧构图。旧版本里依赖外部角色语言的构图全部视为废弃，只保留“白底、手绘、留白、少量批注”的风格密度：

- 传送带两个断点
- 角色在内容机器里拉判断杆
- 角色变漏斗分拣流量/信任/转化
- 角色切素材鱼
- 角色牵承接路径
- 角色拉三层信息源
- 多角色分别拿喇叭/搭桥/开门
- 角色盖章话术工具箱
- 角色举牌看常见坑路径

同类主题也要换新隐喻。例如“承接路径”不一定画路线，可以画 SumSec Observer 把内容尾巴接到门把手；“一鱼多吃”不一定画鱼，可以画它把一个纸团压成几种形状；“漏洞链路”不一定画黑客，可以画它在漏水管道上给证据贴标签。
