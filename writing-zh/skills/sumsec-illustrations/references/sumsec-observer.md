# SumSec Observer 原创人物

## 角色定义

SumSec Observer 是本 skill 的固定原创人物角色，服务于 sumsec.me 的安全研究、AI Agent 和工程系统内容。

默认每张图都要出现 SumSec Observer。它不是吉祥物，不是贴纸，不是可爱装饰，而是一个冷静的安全研究员 / 系统观测员：负责拆链路、看日志、核证据、接工具、修 hook、同步 skill、给风险打标签。

## 外形

- 成人比例的简化人物，头身约 1:5 到 1:6，不要 Q 版。
- 主要由黑色细线绘制，面部极简，表情冷静或疲惫但不卖萌。
- 穿短外套、连帽夹克或轻量风衣，线条克制，不做复杂服装。
- 可选识别件：细框眼镜、遮檐帽、斜挎工具包、手套、便签夹、日志纸带。
- 青蓝只用于一小块识别件，例如袖标、镜片反光、工具线、包带。
- 红橙只用于证据标签、风险贴纸、告警小旗。
- SumSec Core 是角色携带的黑匣徽记、工具芯片或证据封签，不是主角本体。

## 气质

- 克制、冷静、低调。
- 像长期做安全研究、写技术文章、维护 Agent 工具链的人。
- 有一点冷幽默：认真处理一件略荒诞但成立的工程事。
- 不是英雄，不是黑客反派，不是厂商吉祥物。

## 常见动作

让 SumSec Observer 承担核心动作：

- 拿放大镜看日志纸带。
- 用红橙标签标出风险点。
- 把线缆插进低科技调度台。
- 修一个没有触发的 hook 机器。
- 把证据纸压到秤上。
- 在漏洞管道上贴封签。
- 把 Skill 文件夹放进跨平台货架。
- 把 MCP 小邮包分发到不同 agent。
- 站在沙箱玻璃罩外递工具。
- 用夹板记录“入口 / 触发 / 影响 / 修补”。

## 禁止

- 不要画成吉祥物、表情包、Q 版可爱角色或儿童卡通。
- 不要画成黑客兜帽、骷髅、赛博反派或安全厂商代言人。
- 不要画成纯黑实心小人或只剩一个抽象黑块。
- 不要让角色站在角落旁观；它必须参与核心动作。
- 不要让服装、装备或表情抢走结构表达。

## 判断标准

如果去掉 SumSec Observer，图的核心隐喻还能完全成立，说明角色太装饰了；要重写提示词，让角色成为执行动作的人：看、贴、接、修、称、分拣、记录或封存。
