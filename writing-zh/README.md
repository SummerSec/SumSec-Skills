# Writing-ZH Plugin

中文写作辅助插件。包含：

- **humanizer-zh** — 去除文本中 AI 生成痕迹，使中文写作更自然
- **creating-blog-web-ppt** — 将 Markdown 文章转为网页版 PPT，支持 slide-writer 工作流
- **khazix-writer** — 卡兹克公众号长文写作风格
- **sumsec-illustrations** — 为 sumsec.me 风格技术文章生成 SumSec Observer 正文配图

## 安装

通过根 marketplace 安装本插件：

```bash
# Claude Code
/plugin install writing-zh@sumsec-skills
```
