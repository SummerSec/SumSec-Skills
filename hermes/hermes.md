# SumSec-Skills

Home: https://github.com/SummerSec/SumSec-Skills

A collection of reusable Agent Skills organized into four plugin categories:

| Plugin | Directory | Purpose |
|--------|-----------|---------|
| writing-zh | writing-zh/ | Chinese writing: de-AI-fy, markdown-to-slides, SumSec article illustrations |
| dev-tools | dev-tools/ | Git, chat history, doc lookup (context7) |
| agents-dev | agents-dev/ | Skill/plugin/agent development |

Skills are at `<plugin>/skills/<name>/SKILL.md`. Match task intent to skill `description` frontmatter.
