# Taste Skill Plugin

Cross-platform wrapper for [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), an MIT-licensed collection of frontend design and visual-direction Agent Skills.

The canonical skill sources live in the `taste-skill-upstream` git submodule and are synchronized into `taste-skill/skills/` by the repository sync script.

## Install

Claude Code:

```bash
/plugin install taste-skill@sumsec-skills
```

Codex:

```bash
codex plugin marketplace add SummerSec/SumSec-Skills --ref master
```

Then install `taste-skill` from the SumSec Skills marketplace.
