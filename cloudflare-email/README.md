# Cloudflare Email Plugin

Agent skill for `cloudflare_temp_email` mailboxes.

- **cf-temp-mail-agent-mail** - read inbox messages, fetch parsed mail, and send email using a user-provided Address JWT and API base URL.

## Install

Claude Code:

```bash
/plugin install cloudflare-email@sumsec-skills
```

Codex:

```bash
codex plugin marketplace add SummerSec/SumSec-Skills --ref main
```

Then install `cloudflare-email` from the SumSec Skills marketplace.
