# Agents-Dev Plugin

Agent 开发生态插件。包含来自 claude-plugins-official 的 5 个插件技能，以及本仓库的 multi-platform-plugin-guide。

## 安装

```bash
/plugin install agents-dev@sumsec-skills
```

## 来源

- **skill-creator**、**hookify**、**plugin-dev**、**claude-md-management**、**agent-sdk-dev** — 来自 [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)
- **skill-optimizer** — 本仓库维护的 Skill 审计优化
- **multi-platform-plugin-guide** — 本仓库维护的多平台发布指南
